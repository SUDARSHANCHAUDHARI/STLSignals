Laptop-only trend discovery and content drafting tool. Monitors public Reddit discussions, clusters topics into signals, and helps you write original blog posts using Claude Code — zero recurring cost.

**Safety guarantees:** No auto-posting, no copying full Reddit posts, no publishing without manual approval.

## Stack

- **Next.js 15** App Router — TypeScript strict mode
- **SQLite** via Prisma — local file DB, no server needed
- **Tailwind CSS** + shadcn-style component primitives
- **Recharts** for analytics dashboard
- **No external services** — no Supabase, no Vercel, no OpenAI, no email

Content is generated by running Claude prompts in your terminal (Claude Code plan), then pasting the JSON output into the draft form. Free.

## Quick Start

```bash
pnpm install
pnpm setup          # creates .env, pushes SQLite schema, seeds sample data
pnpm dev            # http://localhost:3000/dashboard
```

`MOCK_MODE=true` is the default — the app runs on mock data without any credentials.

## Workflow

```
pnpm setup                     # first time only
pnpm pipeline                  # fetch Reddit posts → detect signals
# open /signals → click a signal → copy the Claude prompt
# paste it in Claude Code terminal → get JSON output
# go to /drafts/new?signalId=xxx → paste JSON → Save draft
# go to /drafts → review → Approve → Save to disk / Ghost CMS
```

## Environment Variables

Copy `.env.example` to `.env` and fill in values. Never commit `.env`.

### Always required

| Variable | Default | Description |
|---|---|---|
| `DATABASE_URL` | `file:./stl-signals.db` | SQLite file path |
| `MOCK_MODE` | `true` | Set `false` to use real DB and Reddit API |

### Required for live Reddit ingestion

| Variable | Description |
|---|---|
| `REDDIT_CLIENT_ID` | Reddit OAuth app client ID |
| `REDDIT_CLIENT_SECRET` | Reddit OAuth app client secret |
| `REDDIT_USER_AGENT` | User-agent string (e.g. `STLSignals/0.1 by YourUsername`) |
| `AUTHOR_HASH_SECRET` | Key for HMAC-SHA256 author hashes. Unset = no author hash stored |

Get credentials at [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps) — create a "script" type app.

### Optional

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Public URL for sitemap + RSS. Default: `http://localhost:3000` |
| `GHOST_URL` | Ghost CMS URL for one-click publish (e.g. `https://yourblog.ghost.io`) |
| `GHOST_ADMIN_KEY` | Ghost Admin API key — format `id:secret` |

## Architecture

```
Reddit API (OAuth)
    ↓  pnpm pipeline → fetch-reddit job
RawPost (SQLite)
    ↓  detect-signals job (keyword clustering)
Signal (SQLite)
    ↓  /signals/[id] → copy Claude prompt → run in terminal → paste JSON
Draft (SQLite) → editorial review in /drafts
    ↓  Approve
Export → posts/[slug].md  or  Ghost CMS API
    ↓
/blog/[slug] (local preview), /feed.xml, /sitemap.xml
```

| `/analytics` | Velocity KPIs, trend chart, topic bar chart |
| `/sources` | Reddit source management |
| `/settings` | Env status, DB stats, pipeline trigger |
| `/blog` | Public blog (ISR, 1h cache) |
| `/feed.xml` | RSS feed |
| `/sitemap.xml` | Sitemap |

## Safety Rules

- Store only Reddit post metadata and short snippets (≤ 280 chars)
- Keyed (HMAC-SHA256) author hashing — no Reddit usernames stored
- No auto-posting or auto-commenting to Reddit
- Human approval required before any content is published
- Generate original analysis from metadata patterns — never copy post content verbatim
- Attribute published posts: _"Signals observed from public Reddit discussions"_
